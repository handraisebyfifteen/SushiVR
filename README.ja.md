# Sushi VR

寿司をテーマにした WebXR アプリです（開発中）。
Meta Quest などの VR ヘッドセットのブラウザで URL を開くだけで、インストールなしで遊べることを目指しています。

> 開発中です。昭和の寿司屋の板場に座り、ハンドトラッキング（手の動きの読み取り）だけで握りを1貫ずつ作って出せます。遊び方の詳しい説明は英語版にあります。

## 朝の仕込み

毎日、開店前の仕込みから始まります。仕込みの間は、お客はまだ来ません。おひつは空で始まります。ケースの中身は難易度で変わります。難易度は、帳場の壁(電話と呼び出しボタンの間)の木の札に出ています。魚屋さんに電話するまでは、札を指さしてつまむと切り替わります(次からも覚えています)。

- かんたん:仕込む品はケースが空、仕込まない品は満タンで始まります(職人が用意した分の給料がかかります)。毎日まっさらから始まります。
- 本格:ケースの残りが次の日に持ち越されます(その日を締めたときにブラウザに保存。1日目は空のケース)。自分でケースを見て、要るものを注文します。日持ちさせてよいのは、マグロと火を通したもの(穴子・玉子・タコ・鮑・かんぴょう・稲荷の揚げ)だけです。ウニといくらは2営業日、ツマものは3日です。ほかの品は、前の日の残りが朝にケースから下げられます(ケースの上にお知らせが出ます)。ツマもの(きゅうり・大葉・たくあん・梅肉)は八百屋さんから直接、魚と一緒に届いて足りない分が補われます。電話では頼まず、支払いは別の行になります。店のお金も持ち越されます。50万円から始まり(`src/tuning.ts` の `START_FUNDS`)、売上が入り、魚屋さん・八百屋さん・人件費が出ていきます。借金はできません。魚屋さんは、払える分までしか注文を受けません(注文票に残りの予算が出ます。八百屋さんの分は先に取っておきます)。職人とアルバイトは、1時間分の給料がないと来てくれません。お金が次の仕事の分を下回ると、アルバイトは帰り、職人は次の魚に手を付けません。出来合いの品は、値段の分で4人前がケースいっぱいです(車海老4本、貝は4つずつ)。稲荷の揚げは12枚で1セット、甘海老は1シート18尾(6尾×3列、2尾付けで9貫)です。

時間は実際の店より速く進みます。仕事は並べて進めます。ご飯と鍋を先に火にかけ、煮えている間に魚を切ります。

1. 右手側、通路の右端の壁の帳場にある黒電話を指さしてつまむと、受話器が上がって魚屋さんに電話がかかります。かんたんでは、魚屋さんが「おまかせ」で持ってきてくれます。本格では、受話器が上がったまま注文します。
   - ケースに手を入れると戸が開き、品ごとに名前と在庫が出ます(売り切れの品も)。品をつまむと注文に入ります。つまむたびに次の量になり、最後はなしに戻ります。
   - 仕込む品は、その材料を注文します。マグロはどれをつまんでもマグロの腹(16分の1か8分の1)、ハマチは四分の一か半身、ほかは1つずつです。仕込まない品は、そのまま出せる形で、ケース半分か満タン分です。
   - ケースの左端の上の伝票に、注文と代金が出ます。電話をもう一度指さしてつまむと、電話を切ります。
   - 届くのは注文した分だけです(そのまま出せる品は、すぐケースに入ります)。届いた分は全部払います(`src/fish-order.ts`)。
   - 少しすると、発泡スチロールの箱が、まな板の左に届きます(中のものを全部仕込み終わると、空の箱は片付きます)。丸の魚の長い箱は、後ろの流しの左横の台に届きます。その間に、体ごと後ろの流しへ振り向いて手を洗います(洗っていない手では魚に触れません)。
   - 遠くのもの(電話・呼び出しボタン・給湯器・のれん・お勘定のお客・作業台・ガス台)は、手を前へ伸ばし、ほかの指を握って人差し指で指し、つまみます。
2. ご飯を炊きます。作業台の前へ移り、台の下のガス炊飯器を指さしてつまむと、火が点きます。炊けると火は自然に消え、蒸らしに入ります(台の上に残り時間が出ます)。
3. ガス台。箱の一番上に、魚屋さんが下処理を済ませたタコ・穴子・鮑・かんぴょうが入っています。それぞれを取って(どちらの手でも)、ガス台のその品の鍋の上で離します。ガス台の前からも、カウンターの方へ向けば箱に手が届きます。火口ごとに、ガス台の正面につまみがあります。短くつまむと強火で点き、もう一度で消えます。つまんだままでいると、強火・中火・弱火と一段ずつ下がります。
   - タコ:強火で、ぐらぐら沸かして炊きます。炊けたあとも煮続けると、硬くなります。
   - 穴子:煮汁を90℃に保って煮ます(鍋の上の数字が温度計です)。強火で上げてから、沸く前に弱火へ落とします。沸かすと身が崩れます。
   - かんぴょう・鮑:煮汁がなくなるまで煮切ります(鍋の上に残りが出ます)。なくなったら、焦げる前に火を止めます。
   - 煮えたら火を止め、鍋から出して、ケースの上で離します(まな板の前に戻って)。使った鍋は片付きます。
   - 玉子(本格だけ。このお店のやり方:すり身入りの厚焼きを店で焼く):生地は店で作ります。作業台の奥、流し側の角にすり鉢があります。箱からすり身と卵を取り、すり鉢の上で離すと、すり身が入り、卵のボウルが横に置かれます。すりこぎをつまんでぐるぐる回し、すり身がなめらかになるまで擂ります。卵のボウルをすり鉢の上で離して卵を入れ、また泡立つまで回して混ぜます。ガス台の横の壁の網の隣に、四角い銅の玉子焼き鍋が掛かっています。持ち手をつまんで外し、鍋が片付いた火口の上で離します。すり鉢の手前の縁をつまみ、鍋の上で離すと流し込まれます(すり鉢は片付きます)。その火口を弱火にします(強火や中火は早く焼けますが、下の面が焦げます)。片面が焼けたら、持ち手をつまんで持ち上げると一度返ります(板をかぶせて返し、鍋に戻すところまでを1つの動きにしています)。もう片面も焼けたら火を止め、玉子をつまんで出し、ケースの上で離します。時間は目安で、点にはなりません。焦げた面がある時だけ、取れる貫数が少し減ります(`src/tamago-system.ts`)。
4. 魚の柵取り。左手で箱の魚をつまみ(上にあるものから)、まな板の上で離します。魚は紙で包んだ上からビニールに入っています。左手で押さえ、右手で包みをつまんで引き離します。これを2回です。左手で押さえ、包丁を白い線に沿って引きます。線は、魚に沿って手前に引くもの、横に切るもの、まな板に沿って低く削ぐもの(皮)があります。包丁は刃を立てて、右から左下へ引くのが基本です(刀やバットと同じストローク)。刃を寝かせるのは、皮や中骨を削ぐ時だけです。わさびの皿は、営業中以外は伏せてあります。
   - マグロ(まぐろ屋から買う腹の8分の1・16分の1):皮目を切り落としてから、大トロ・中トロ・赤身に分けます。
   - カツオの半身:血合いに沿って背と腹に分けます。背は血合いを落とし、皮は包丁で削ぎます(引くと身割れしやすいため)。腹は首まわりの硬い皮と血合いを落とし、氷の上へ戻します(7で焼きます)。
   - イカ:胴から足を引き抜き、ワタを切り離し、足と胴をそれぞれ開いて平らにします。身の皮は手で剥ぎ(包みと同じく引き離す)、ペーパー箱の紙で水分を拭きます。
   - できた柵をつまんでケースの上で離すと、その品の場所に入ります(イカの足はゲソ)。包み・皮・血合い・ワタ・使ったペーパーは、まな板の右手前にたまります。左の足元のゴミ箱(手が近づくとふたが開く)に捨てます。
5. 丸の魚(このお店のやり方:中型の魚は丸で、大きい魚はケースに入る分だけ買う)。しまあじとヒラメは丸で、ハマチは半身で、長い発泡の箱に入って、流しの足元(食器棚の前)の低い台に届きます。振り向いて流しの横の台(左手側)を指さしてつまむと、その前に立ち、箱から魚を取れます。流しを指さしてつまむと、流しの前に立ちます。
   - 水洗い:魚を箱から取って、流しの上に渡した水洗い用のまな板に置きます。流しの右の台にある鱗取りをつまんで、魚の上で何度もこそげると、鱗が取れます。魚をつまんで少し持ち上げると裏返るので、裏も同じようにします。鱗取りの隣の出刃包丁を拳で握って、頭を落とします(しまあじは腹も開きます)。左手で魚を押さえ、右手でワタをつまんで引き出したら、水を流して腹の中を手でこすって洗います。頭とワタは、流しの横のゴミ箱に捨てます。
   - おろす:洗った魚を持ってまな板の前へ戻り、まな板に置きます。しまあじは三枚おろしです。腹を手前にして、腹側と背側を骨まで切り、身を持ち上げて外します。裏返して同じようにし、中骨は捨てます。ヒラメは五枚おろしです。黒い方を上にして、真ん中を骨まで、両側はヒレの際を切り、背側と腹側の身を外します。裏返して白い方も同じにします。
   - 身ごとの仕事:腹骨をすき取り、骨抜き(まな板の奥、ペーパー箱の右)で小骨を抜きます。骨抜きはつまんで持ち、先を小骨に当てて上へ抜きます。次に、包丁で皮を引きます(中型の魚は柵にする前に皮を引く)。最後に、背と腹の柵に分けます。ヒラメの身は、代わりにエンガワを切り離します。ハマチの半身は、包みを外し、腹骨・小骨・皮のあと、背と腹に分けます。
   - 柵とエンガワは、全部ケースに入れます。
   - 本格では、小肌とサバもその日に仕込みます(このお店のやり方)。
     - 小肌は丸で届き、1日8尾を丸づけで8貫にします。流しの洗い板の右にばらで置かれ、左に氷を入れたボウルがあります(並べない)。同じ魚がいくつもあるときは、工程ごとにまとめてやります(狭い店の動き方)。鱗を取ったら、1尾ずつ真ん中へ取って頭を落とし(1尾ずつ。まとめて落とさない)、氷の上へ。頭を全部落としたら、1尾ずつ氷から取って背びれを切り落とし、腹を切り落とします(小肌は腹を裂きません。ワタは腹と一緒に取れます)。全部洗ってまた氷の上へ。魚は頭を左に置きます(左利きなら逆)。
     - まな板でも同じで、先に全部を腹から開き(腹開き)、そのあと全部の中骨をすき取ります。捌く時は頭を右に置き換えます(腹は手前のまま。頭を落とす時は左)。開いたものは、重ねて一列に並べます。
     - サバは、しまあじと同じように水洗いして三枚におろし、腹骨と小骨を取ります。皮は残します(握る前に手で剥ぐ)。
     - 塩(両面):小肌は流しの横の台の平ざる。まずザルに塩をふり(塩の器から塩をつまんで、ザルの上で指を開く。落ちた所が白くなる)、開いた小肌を皮を上にして一列に重ねて並べ、上からも白くなるまで塩をふります。サバはステンレスのバットに入れて、白くなるまで塩をふります。
     - 置く:小肌はだいたい40分、その日の大きさで5分前後します(魚屋さんが電話で言います)。サバは2〜3時間。ここでは1分が1秒です。時間は食器棚の流し側の側面(お客さんから見えない所)に掛けたキッチンタイマーに出ます。0になると鳴って点滅します。
     - 小肌の塩を落とす:流しに置いた水を張ったボウルに小肌を入れると、塩が落ちます。そのあいだにザルの縁をつまんで蛇口の下で洗います。ザルが洗えたら、小肌をボウルからきれいなザルへ上げ、一列に重ねて並べて水を切り、そのまま酢へ移せます。水と水切りは時間ではなく、手順です。
     - サバの塩を落とす:バットの手前の縁をつまんで蛇口の下に持っていき、塩が落ちたら離します。
     - 酢:酢専用のホーローの容器は1つで、台のいちばん奥にあります。小肌が先、サバはそのあとです。魚をつまみ上げて容器の上で離します。小肌は20分、サバは30分。使い終わったザルやバットは片付きます。
     - 取り出す:容器の上でつまんで持ち上げ、ケースの上で離します。時間はこのお店の目安で、親方が教えてくれます。店によってやり方が違うので、時間で点や数は変わりません(`src/cure-system.ts`)。時間の少し前に、親方が「用意して」と流しの横の台へ呼びます。
6. シャリ(このお店のやり方:合わせ酢は米酢の作り置き、あおがない)。炊き上がったら、もう一度炊飯器を指さしてつまむと、作業台の飯台にあけられます。合わせ酢の器を持って、ご飯の上にかざすと打たれます。しゃもじを持って、ご飯を切るように何度も往復させます。次に、座る位置の横の台からおひつを持ってきて(ふたは台に残します)、作業台の飯台の横に置きます。しゃもじでシャリをすくって、おひつへ何回も移し(6回)、おひつを元の台へ戻します。営業のシャリは、このおひつから取ります。飯台としゃもじは壁に戻ります。
7. カツオの腹。氷の上から、まな板へ移します。手前の端にある金串の輪をつまんで奥へ押し込み、皮目に金串を打ちます。ガス台の横の壁に掛かった網を、鍋が片付いた火口に置きます。網の上に腹を皮目を下にして置き、その火口を強火にします。金串の輪をつまむと、4分の1ずつ回ります。下になった面が焼けます。皮目は焼き目が付くまで、ほかの面は色が変わるまでです。焼けたら金串を持って持ち上げ、氷の上で締めます。それからまな板の上でペーパーで水気を取り、金串を手前に引き抜いて、ケースの上で離します。
8. 掃除をします。
   - 包丁を拭いて置きます。
   - まな板の手前の縁をつまんで振り向き、流しで洗います(もう片方の手でこする)。流しの上で離すと立てかけられ、しばらく乾かしてから板場に戻します。
   - ガス台の火は全部消します。
   - 石けんで手を洗います。
   - 最後に、客席の奥の店の入口に掛かっているのれんを指さしてつまむと、のれんが外に掛かって開店し、最初のお客が入ってきます。

切り口が線に近いほど高く評価されます。切り口が曲がると身が無駄になり、柵から取れる枚数(売れる貫数)が減ります。ガス台の品も評価されます(硬くなったタコ、崩れた穴子、焦げたかんぴょう、焦げたり片面しか焼けていない腹は、取れる貫数が減ります)。仕込みが終わると、取れた貫数がまな板の上に出ます(仕込みは店によってやり方が違うので、評価の言葉は出しません)。ハマチは季節で大きさが変わる魚です(冬は大型、夏は準大型)。季節を入れるときに、届く形も季節に合わせます。それまでは半身で届きます。

**後ろの列へ一歩**:作業台とガス台は、座る位置からは一歩先です。洗う丸の魚があるあいだは、流しもそうです(座る位置からは、流しの手前の縁にしか手が届きません)。振り向いてどれかを指さしてつまむと、画面がまばたきして、その前に立ちます。そこからもう一方を指せば移り、カウンターの方を向いてまな板を指せば座る位置へ戻ります。開店すると、座る位置に戻ります(`src/place-system.ts`)。

**人を頼む**:ふだんは誰もいません。仕込みの間に、帳場の食品棚の上にある呼び出しボタン(左が職人、右がアルバイトの絵)を指さしてつまむと、その人を呼べます。もう一度でやめになります。呼んでいる間は、ボタンの上のランプが点きます。呼ばれた人は、通路の左端の調理場の出入口から出てきて仕事をし、終わると調理場へ戻ります(シンプルな人形です)。

- 職人(時給2,000円):箱のところへ歩いてきて、残っている魚を調理場へ持っていき、柵にしてケースに入れてくれます。ガス台の材料は煮て、職人が切ったカツオの半身の腹は焼いて入れてくれます。シャリは親方(自分)の仕事です。
- アルバイト(時給1,300円):仕込みが終わると、まな板のところへ来て、ゴミを捨て、まな板を洗ってくれます。

給料は、仕事ごとに決めた時間分を払います(`src/tuning.ts` の `COOK_MINUTES`・`CLEANUP_MINUTES`)。かんたんモードで自動で満タンになる品も、職人が用意した分として給料がかかります。全部を自分でやれば給料はかからず、一番もうかります。

## 店のまわり

- 振り向き:ヘッドセットでは、座ったまま体ごと後ろを向くだけです(画面の切り替えはありません)。顔がカウンターから120度より後ろを向くと「後ろ向き」、60度より前に戻ると「カウンター向き」になります。横(帳場やガス台)を見ただけでは変わりません。
- ネタ表:流しからガス台の上の壁に、木札が30枚並んでいます。品の名前が日本語の縦書きで、右から読みます(ゲーム内で日本語が出るのはここだけです)。札に値段は書きません。値段は `src/tuning.ts` の値段表で決まっています。
- 帳場:お客から見えにくい、通路の右端の壁です。手前に食品棚(調味料が分かるように並べてあり、ラベル付き:醤油・みりん・酒・米酢・塩・砂糖)とその上の呼び出しボタン、奥の食器棚との間に、電話台の黒電話と、その上に帳簿の板があります。
- 長のれん:カウンターの右端の、客席と板場の間の通り口と、通路の左端の調理場の出入口に、藍色の長いのれんを掛けました。客席からは、帳場が少しだけ見えます。調理場の明るさは、のれんの合わせ目と裾から見えます。

## お金と閉店

- 握りを出すと、定価がお客の勘定に付きます(`src/tuning.ts` の `PRICE`。巻物は1本で1注文)。その品の値段と、ここまでの勘定が、お客の頭の上に出ます。
- 出来(拍・わさび・向き・利き手・鮮度・衛生)で、お代わりが変わります。お客は3注文のつもりで来ます。Excellent なら1つ増え(最大6つ)、Poor なら1つ減り、Bad ならお勘定にします。直すところは小さな印で出ます。
- 注文と違う品は「Not my order」で返され、勘定に付きません。作り直します。
- カツオの注文で背か腹の指定がなければ、背と腹の2貫を1つずつ出します。
- お勘定:食べ終わったお客が「Check, please」と言います。お客を指さしてつまむと、勘定を払って入口から帰ります。次のお客は入口から入ってきます。
- お茶:お客は、最初の1貫のあとに、ときどきお茶を頼みます。お茶は粉茶で、電話の下の低い棚にある給湯器で、お客から見えないところで入れます。
  - 誰も呼んでいないときは自分で出します。給湯器を指さしてつまむと、少しして、まな板の右の台に湯呑みが出ます。それをつまんでケースの上を越え、つけ台の上で離すと、お客の前に置かれます。
  - 待たせすぎると、そのお客の注文が1つ減ります。
- 営業中のアルバイト:ボタンで呼ぶと、帳場の長のれんの奥にいて、通り口から出てきます。新しいお客を入口から席まで案内し、頼まれたお茶を持っていきます(お茶1杯・案内1回ごとに、決めた分数の給料)。お勘定、営業中のまな板拭き・布巾洗いは、板前の仕事(衛生)なので、自分でやります。
- 閉店:店の入口の外に掛かったのれんを指さしてつまむと、のれんを中にしまいます(指さしで腕を伸ばした手は、ネタケースの上を通っても扉を開けず、何も取りません)。座っているお客の注文がラストオーダーです。お客が勘定を払って帰ると、帳場の電話の上にある帳簿の板が、その日の締めになります(カウンターの上にお知らせが出ます)。帳簿の板には、営業中も今日の数字が出ています。
  - 売上
  - 魚屋さんへの支払い(届いた分は、売れ残っても全部払います)
  - 給料
  - もうけ(または損)
- 次の日は、ページを読み込み直すと始まります(本格では、ケースに残った分とお金を持って次の日になります)。本格の帳面には、店のお金(と朝の額)、4万円を切った時の注意、朝に捨てた分(金額。仕入れた日に払い済みの参考)、出した握りの出来ごとの数も出ます。

練習モードのキー(仕込み):9 運ぶ(魚・柵・ゴミ)、0 引き離す(包み・足・皮)、X 切る、- ペーパー、[ まな板(持ち上げ・洗う・立てかける・戻す。間に T で振り向く)、] のれん(開店と閉店)、= 電話、Shift+= 難易度の札、; 職人のボタン、' アルバイトのボタン(どれも指さしてつまむ)。本格の電話中は、Tab で半分を切った品を全部、満タン分注文してから電話を切ります。Shift+8 で、本格の店を1日目からやり直します(次の読み込みから)。Shift+9 で、本格の店のお金をすぐ1万円にします(上限を試す用)。Shift+K で利き手を左右切り替えます(朝、電話の前だけ)。営業中は、\ お勘定、, 給湯器(Shift+, でお客がお茶を頼む。練習用)、. 湯呑みをつけ台へ。O は仕込みを飛ばして開店します。後ろの列では、A でシャリの次の手順、Enter でガス台の次のこと(つまみ・鍋に入れる・ケースへ出す・網・カツオの腹)をします。どちらも、必要なら移動と振り向きもします。/ で見ている方へ移り(作業台・ガス台・まな板へ戻る)、Tab で親方が言っていることをします(丸の魚の仕事、鱗取り・裏返し・出刃・水洗い・骨抜きも Tab で)。` で手ブレ試験(手が揺れ、ときどき一瞬見失う。実機なしで判定の強さを確かめる用)。

このゲームは手だけで操作します(ハンドトラッキング)。コントローラーを持っていて手が見えないときは、目の前にお知らせが出ます。パソコンのエミュレーターは最初、立った人(目の高さ1.6m、手は胸の高さ)とコントローラーの状態で始まるので、開発中は起動時に、手のモードで、座った目の高さからまな板を見下ろし、両手をまな板の上に置いた状態にします(上の手の絵のボタンで、手とコントローラーはいつでも切り替えられます)。

**視線(Meta VR Glasses)**:目の向きを読める機械では、指さしで選ぶもの(電話、呼び出しボタン、給湯器、お勘定のお客、のれん)を、見てつまむ(空いている手のどちらでも)でも選べます。見ている間は、指さしと同じように光ります。手元で何かを持ち上げたつまみ(ネタ、湯呑み、箱の魚)は作業なので、選んだことになりません(`src/gaze.ts`)。Quest 3 / 3S は目の向きを読めないので、指さしだけです。メガネの視野は狭く(左右37°、上25°、下43°)、まな板を見下ろしたとき、ネタケースの両端、包丁、布巾、発泡スチロールの箱、おひつは視野の外になり、頭を向けて見ます。エミュレーターでメガネを試すには、`iwsdk.config.json` の `dev.emulator.device` を `metaVRGlasses` にします(ふだんは `metaQuest3`)。

判定は Meta の手の設計ガイドに合わせています。手を0.4秒未満見失っても、持った物は落としません(握るときに片手がもう片手を隠すため)。手には振動がないので、取る・置く・押す・結果のたびに短い音が鳴ります。

## ネタケース

幅150cmのケースに31品が並びます。左から順に、次のとおりです。

- 左手（ネタの手）で取る品：玉子、鮑、タコ、イカ、ゲソ、ヒラメ、シマアジ、ハマチ、カツオ(背・腹)、マグロ（赤身・中トロ・大トロ）、コハダ、アジ、しめ鯖、車海老、甘エビ、ホタテ、赤貝、トリ貝、穴子、稲荷の揚げ
- 右端の、右手で扱う品：ウニ（白木の折に身を重ねて並べ、小さな木べら付き）、イクラ（素朴な白い陶器の浅鉢に盛り、スプーン付き）、鉄火用マグロ、胡瓜、干瓢、沢庵、梅肉、大葉（巻物の具は今後使います）

引き戸5枚は、どちらの手が近づいても自動で開きます。手を入れると、指先の品が光って名前が出ます。同時に、開いた扉の奥の品が、ケースの上に2倍の大きさで名前付きで浮かびます。

**軍艦（ウニ・イクラ）**の作り方は次のとおりです。

1. 右手で手水とシャリを取ります。
2. 左手でまな板の左奥の海苔缶から帯をつまみます(手を近づけるとふたが開きます)。
3. 両手を合わせると、海苔がシャリに巻き付きます。
4. わさびの注文があれば、人差し指で付けます。
5. 右手でウニは木べら、イクラはスプーンを取り、軍艦の上で離すと乗ります。

海苔はすぐしんなりするので、鮮度は巻いた時から数えます。

**稲荷**は関東風の俵形です。作り方は次のとおりです。

1. 右手で手水とシャリを取ります。
2. 左手でケースから味付けの揚げを取ります。揚げは、パックから汁ごとステンレスの中子に移してあります。
3. 両手を合わせると、シャリが揚げに入ります。
4. 左手のこぶしで、拍に合わせて口を折り込みます。

わさびは付けません。

**巻物**は6種です(かんぴょう巻・鉄火巻・かっぱ巻・おしんこ巻・梅しそ巻・梅きゅう巻)。巻物の注文が入ると、まな板の上に巻き簾が広がります。作り方は次のとおりです。

1. 左手で海苔缶から半分の海苔を取り、巻き簾の上で離します。
2. 右手で手水とシャリを取り、開いた手で海苔の上を左右になでて広げます。
3. わさびの注文があれば付けます。
4. 右手でケースの右端から具を取り、真ん中に置きます(梅しそは大葉 → 梅肉、梅きゅうは梅肉 → 胡瓜)。
5. 両手で巻き簾を前へ押して巻き、両手のこぶしを拍に合わせて締めます。
6. 包丁で目印の線を3回切ります。1回目で半分にすると、2本が横に並びます。かんぴょう巻は六切り(2本まとめて3等分)、ほかは八切り(半分、4本並べてもう一度半分)です。包丁を拭いて置きます。
7. 断面を上にして立った巻物をつまんで下駄に置き、出します。下駄は座ったまま腕を伸ばした先より少し遠いので、ケースの向こう半分の上(ガラスの上から手を入れる)で離せば、下駄に置いたことになります(握りも同じ。`src/layout.ts` の `GETA_ZONE_*`)。

握りの形は、お店のやり方の舟形(底が平らで、上がゆるく盛り上がり、両端が丸く細くなる)です。シャリは約29g(長さ6.5cm・幅2.9cm・高さ2.4cm)。手水を付けて取ったシャリは、はじめはばらけた塊で、拳で丸めると玉になります。そこから三手の一手ごとに締まります。一手目で上(ひっくり返した後の底)が平らになり、二手目で形が決まってネタがかぶさり、三手目で左右がそろって仕上がります。ネタは長さ7.5cm・幅3cm・厚さ6mm(柵から切った場合)で、シャリに沿ってかぶさります。玉子・鮑・帆立のように硬いネタは、あまり曲がりません。形は `src/scene-assets/lib/nigiri-form.ts` で作っています。

握りは23種です。柵から切る14種(マグロ、カツオの背と腹、白身とヒラメのエンガワ、しめさば、イカ、タコ、鮑、玉子)は、1枚切るごとに短くなります。仕込み済みの9種は、1枚ずつ指に取ります。なくなった品は売り切れになり、翌朝の仕込みまで注文にも出ません。数と並び順は `src/menu.ts` で変えられます。

English version: [README.md](README.md)

## 動かし方

Node.js 22.12 以上が必要です（[`.nvmrc`](.nvmrc) 参照）。

```sh
npm install
npm run dev
```

開発用のブラウザが起動します。VR ヘッドセットがなくても、内蔵のエミュレーター（IWER）でパソコン上から VR 操作を試せます。
ブラウザ内の Runtime / Editor の切り替えで、アプリの実行画面とシーン編集画面を行き来できます。

本番用ファイルの作成:

```sh
npm run build   # dist/ に出力
```

## 制作ルール

- アプリ内の文字はすべて英語
- 実在の企業名・ブランド名・商品名は使わない
- 外部の 3D モデル・画像・音・フォントは使わず、図形をコードで作る
- Meta Quest 実機で 60fps 以上を目標にする
- 使用素材はすべて [CREDITS.md](CREDITS.md) に記録する
