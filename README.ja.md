# Sushi VR

寿司をテーマにした WebXR アプリです（開発中）。
Meta Quest などの VR ヘッドセットのブラウザで URL を開くだけで、インストールなしで遊べることを目指しています。

> 開発中です。昭和の寿司屋の板場に座り、ハンドトラッキング（手の動きの読み取り）だけで握りを1貫ずつ作って出せます。遊び方の詳しい説明は英語版にあります。

## 朝の仕込み

毎日、開店前の仕込みから始まります。仕込みの間は、お客はまだ来ません。仕込む品はケースが空で始まります。仕込まない品は、難易度「かんたん」なので満タンで始まります(`src/tuning.ts` の `DIFFICULTY`)。

1. 右手側、通路の右端の壁の帳場にある黒電話を指さしてつまむと、受話器が上がって魚屋さんに電話がかかります。魚屋さんは「おまかせ」で足りないものを持ってきてくれます。少しすると、発泡スチロールの箱が、まな板の左に届きます(中の魚を全部仕込み終わると、空の箱は片付きます)。その間に、体ごと後ろの流しへ振り向いて手を洗います(洗っていない手では魚に触れません)。
   - 遠くのもの(電話・呼び出しボタン・給湯器・のれん・お勘定のお客)は、手を前へ伸ばし、ほかの指を握って人差し指で指し、つまみます。
2. 左手で箱の魚をつまみ(上にあるものから)、まな板の上で離します。魚は紙で包んだ上からビニールに入っています。左手で押さえ、右手で包みをつまんで引き離します。これを2回です。
3. 左手で押さえ、包丁を白い線に沿って引きます。線は、魚に沿って手前に引くもの、横に切るもの、まな板に沿って低く削ぐもの(皮)があります。
   - マグロ(まぐろ屋から買う腹の8分の1・16分の1):皮目を切り落としてから、大トロ・中トロ・赤身に分けます。
   - カツオの半身:血合いに沿って背と腹に分けます。背は血合いを落とし、皮は包丁で削ぎます(引くと身割れしやすいため)。腹は首まわりの硬い皮と血合いを落とし、氷の上へ戻します(皮目を焼くのはガス台の段階で作ります)。
   - イカ:胴から足を引き抜き、ワタを切り離し、足と胴をそれぞれ開いて平らにします。身の皮は手で剥ぎ(包みと同じく引き離す)、ペーパー箱の紙で水分を拭きます。
4. できた柵をつまんでケースの上で離すと、その品の場所に入ります(イカの足はゲソ)。包み・皮・血合い・ワタ・使ったペーパーは、まな板の右手前にたまります。左の足元のゴミ箱(手が近づくとふたが開く)に捨てます。
5. 掃除をします。
   - 包丁を拭いて置きます。
   - まな板の手前の縁をつまんで振り向き、流しで洗います(もう片方の手でこする)。流しの上で離すと立てかけられ、しばらく乾かしてから板場に戻します。
   - 石けんで手を洗います。
   - 最後に、客席の奥の店の入口に掛かっているのれんを指さしてつまむと、のれんが外に掛かって開店し、最初のお客が入ってきます。

切り口が線に近いほど高く評価されます。切り口が曲がると身が無駄になり、柵から取れる枚数(売れる貫数)が減ります。評価と歩留まり(何%取れたか)がまな板の上に出ます。ガス台の仕込み(タコは強火で炊く、穴子は90°を保って煮る、かんぴょう・鮑は煮切る、カツオの腹は皮目を焼く)と、白身を丸ごとおろす仕込みは、この後の段階で作ります。それまでは、その品は満タンで始まります。

**人を頼む**:ふだんは誰もいません。仕込みの間に、帳場の食品棚の上にある呼び出しボタン(左が職人、右がアルバイトの絵)を指さしてつまむと、その人を呼べます。もう一度でやめになります。呼んでいる間は、ボタンの上のランプが点きます。呼ばれた人は、通路の左端の調理場の出入口から出てきて仕事をし、終わると調理場へ戻ります(シンプルな人形です)。

- 職人(時給2,000円):箱のところへ歩いてきて、残っている魚を調理場へ持っていき、柵にしてケースに入れてくれます。
- アルバイト(時給1,300円):仕込みが終わると、まな板のところへ来て、ゴミを捨て、まな板を洗ってくれます。

給料は、仕事ごとに決めた時間分を払います(`src/tuning.ts` の `COOK_MINUTES`・`CLEANUP_MINUTES`)。かんたんモードで自動で満タンになる品も、職人が用意した分として給料がかかります。全部を自分でやれば給料はかからず、一番もうかります。

## 店のまわり

- 振り向き:ヘッドセットでは、座ったまま体ごと後ろを向くだけです(画面の切り替えはありません)。顔がカウンターから120度より後ろを向くと「後ろ向き」、60度より前に戻ると「カウンター向き」になります。横(帳場やガス台)を見ただけでは変わりません。
- ネタ表:流しからガス台の上の壁に、木札が30枚並んでいます。品の名前が日本語の縦書きで、右から読みます(ゲーム内で日本語が出るのはここだけです)。札に値段は書きません。値段は `src/tuning.ts` の値段表で決まっています。
- 帳場:お客から見えにくい、通路の右端の壁です。手前に食品棚とその上の呼び出しボタン、奥の食器棚との間に、電話台の黒電話と、その上に帳簿の板があります。
- 長のれん:カウンターの右端の、客席と板場の間の通り口と、通路の左端の調理場の出入口に、藍色の長いのれんを掛けました。客席からは、帳場が少しだけ見えます。調理場の明るさは、のれんの合わせ目と裾から見えます。

## お金と閉店

- 握りを出すと、定価がお客の勘定に付きます(`src/tuning.ts` の `PRICE`。巻物は1本で1注文)。その品の値段と、ここまでの勘定が、お客の頭の上に出ます。
- 出来(拍・わさび・向き・利き手・鮮度・衛生)で、お代わりが変わります。お客は3注文のつもりで来ます。Excellent なら1つ増え(最大6つ)、Poor なら1つ減り、Bad ならお勘定にします。直すところは小さな印で出ます。
- 注文と違う品は「Not my order」で返され、勘定に付きません。作り直します。
- カツオの注文で背か腹の指定がなければ、背と腹の2貫を1つずつ出します。
- お勘定:食べ終わったお客が「Check, please」と言います。お客を指さしてつまむと、勘定を払って入口から帰ります。次のお客は入口から入ってきます。
- お茶:お客は、最初の1貫のあとに、ときどきお茶を頼みます。お茶は粉茶で、電話の下の低い棚にある給湯器で、お客から見えないところで入れます。
  - 誰も呼んでいないときは自分で出します。給湯器を指さしてつまむと、少しして、まな板の右の台に湯呑みが出ます。それをつまんでケースの上を越え、つけ台の上で離すと、お客の前に置かれます。
  - 待たせすぎると、そのお客の注文が1つ減ります。
- 営業中のアルバイト:ボタンで呼ぶと、帳場の長のれんの奥にいて、通り口から出てきます。新しいお客を入口から席まで案内し、頼まれたお茶を持っていきます(お茶1杯・案内1回ごとに、決めた分数の給料)。お勘定、営業中のまな板拭き・布巾洗いは、板前の仕事(衛生)なので、自分でやります。
- 閉店:店の入口の外に掛かったのれんを指さしてつまむと、のれんを中にしまいます。座っているお客の注文がラストオーダーです。お客が勘定を払って帰ると、帳場の電話の上にある帳簿の板が、その日の締めになります(カウンターの上にお知らせが出ます)。帳簿の板には、営業中も今日の数字が出ています。
  - 売上
  - 魚屋さんへの支払い(届いた分は、売れ残っても全部払います)
  - 給料
  - もうけ(または損)
- 次の日は、ページを読み込み直すと始まります。

練習モードのキー(仕込み):9 運ぶ(魚・柵・ゴミ)、0 引き離す(包み・足・皮)、X 切る、- ペーパー、[ まな板(持ち上げ・洗う・立てかける・戻す。間に T で振り向く)、] のれん(開店と閉店)、= 電話、; 職人のボタン、' アルバイトのボタン(どれも指さしてつまむ)。営業中は、\ お勘定、, 給湯器(Shift+, でお客がお茶を頼む。練習用)、. 湯呑みをつけ台へ。O は仕込みを飛ばして開店します。` で手ブレ試験(手が揺れ、ときどき一瞬見失う。実機なしで判定の強さを確かめる用)。

このゲームは手だけで操作します(ハンドトラッキング)。コントローラーを持っていて手が見えないときは、目の前にお知らせが出ます。パソコンのエミュレーターは最初、立った人(目の高さ1.6m、手は胸の高さ)とコントローラーの状態で始まるので、開発中は起動時に、手のモードで、座った目の高さからまな板を見下ろし、両手をまな板の上に置いた状態にします(上の手の絵のボタンで、手とコントローラーはいつでも切り替えられます)。

**視線(Meta VR Glasses)**:目の向きを読める機械では、指さしで選ぶもの(電話、呼び出しボタン、給湯器、お勘定のお客、のれん)を、見てつまむ(空いている手のどちらでも)でも選べます。見ている間は、指さしと同じように光ります。手元で何かを持ち上げたつまみ(ネタ、湯呑み、箱の魚)は作業なので、選んだことになりません(`src/gaze.ts`)。Quest 3 / 3S は目の向きを読めないので、指さしだけです。メガネの視野は狭く(左右37°、上25°、下43°)、まな板を見下ろしたとき、ネタケースの両端、包丁、布巾、発泡スチロールの箱、おひつは視野の外になり、頭を向けて見ます。エミュレーターでメガネを試すには、`iwsdk.config.json` の `dev.emulator.device` を `metaVRGlasses` にします(ふだんは `metaQuest3`)。

判定は Meta の手の設計ガイドに合わせています。手を0.4秒未満見失っても、持った物は落としません(握るときに片手がもう片手を隠すため)。手には振動がないので、取る・置く・押す・結果のたびに短い音が鳴ります。

## ネタケース

幅150cmのケースに31品が並びます。左から順に、次のとおりです。

- 左手（ネタの手）で取る品：玉子、鮑、タコ、イカ、ゲソ、ヒラメ、シマアジ、ハマチ、カツオ(背・腹)、マグロ（赤身・中トロ・大トロ）、コハダ、アジ、しめ鯖、車海老、甘エビ、ホタテ、赤貝、トリ貝、穴子、稲荷の揚げ
- 右端の、右手で扱う品：ウニ（白木の折に身を重ねて並べ、小さな木べら付き）、イクラ（素朴な白い陶器の浅鉢に盛り、スプーン付き）、鉄火用マグロ、胡瓜、干瓢、沢庵、梅肉、大葉（巻物の具は今後使います）

引き戸5枚は、どちらの手が近づいても自動で開きます。手を入れると、指先の品が光って名前が出ます。同時に、開いた扉の奥の品が、ケースの上に2倍の大きさで名前付きで浮かびます。

**軍艦（ウニ・イクラ）**の作り方は次のとおりです。

1. 右手で手水とシャリを取ります。
2. 左手でまな板の左奥の海苔箱から帯をつまみます。
3. 両手を合わせると、海苔がシャリに巻き付きます。
4. わさびの注文があれば、人差し指で付けます。
5. 右手でウニは木べら、イクラはスプーンを取り、軍艦の上で離すと乗ります。

海苔はすぐしんなりするので、鮮度は巻いた時から数えます。

**稲荷**は関東風の俵形です。作り方は次のとおりです。

1. 右手で手水とシャリを取ります。
2. 左手でケースから味付けの揚げを取ります。揚げは、パックから汁ごとステンレスの中子に移してあります。
3. 両手を合わせると、シャリが揚げに入ります。
4. 左手のこぶしで、拍に合わせて口を折り込みます。

わさびは付けません。

**巻物**は6種です(かんぴょう巻・鉄火巻・かっぱ巻・おしんこ巻・梅しそ巻・梅きゅう巻)。巻物の注文が入ると、まな板の上に巻き簾が広がります。作り方は次のとおりです。

1. 左手で海苔箱から半分の海苔を取り、巻き簾の上で離します。
2. 右手で手水とシャリを取り、開いた手で海苔の上を左右になでて広げます。
3. わさびの注文があれば付けます。
4. 右手でケースの右端から具を取り、真ん中に置きます(梅しそは大葉 → 梅肉、梅きゅうは梅肉 → 胡瓜)。
5. 両手で巻き簾を前へ押して巻き、両手のこぶしを拍に合わせて締めます。
6. 包丁で目印の線を3回切ります。1回目で半分にすると、2本が横に並びます。かんぴょう巻は六切り(2本まとめて3等分)、ほかは八切り(半分、4本並べてもう一度半分)です。包丁を拭いて置きます。
7. 断面を上にして立った巻物をつまんで下駄に置き、出します。

握りの形は、お店のやり方の舟形(底が平らで、上がゆるく盛り上がり、両端が丸く細くなる)です。シャリは約15g(長さ5cm・幅2.3cm・高さ2cm)。手水を付けて取ったシャリは、はじめはばらけた塊で、拳で丸めると玉になります。そこから三手の一手ごとに締まります。一手目で上(ひっくり返した後の底)が平らになり、二手目で形が決まってネタがかぶさり、三手目で左右がそろって仕上がります。ネタは長さ7.5cm・幅3cm・厚さ6mm(柵から切った場合)で、シャリに沿ってかぶさります。玉子・鮑・帆立のように硬いネタは、あまり曲がりません。形は `src/scene-assets/lib/nigiri-form.ts` で作っています。

握りは20種です。柵から切る12種は、1枚切るごとに短くなります。仕込み済みの8種は、1枚ずつ指に取ります。なくなった品は売り切れになり、翌朝の仕込みまで注文にも出ません。数と並び順は `src/menu.ts` で変えられます。

## 動かし方

Node.js 22.12 以上が必要です（[`.nvmrc`](.nvmrc) 参照）。

```sh
npm install
npm run dev
```

開発用のブラウザが起動します。VR ヘッドセットがなくても、内蔵のエミュレーター（IWER）でパソコン上から VR 操作を試せます。
ブラウザ内の Runtime / Editor の切り替えで、アプリの実行画面とシーン編集画面を行き来できます。

本番用ファイルの作成:

```sh
npm run build   # dist/ に出力
```

## 構成

| パス | 内容 |
| --- | --- |
| `iwsdk.config.json` | プロジェクト設定（使うシーン・アセット・XR 機能など） |
| `src/index.ts` | アプリの起点。`World.create()` とシステムの登録 |
| `src/menu.ts` | メニューとネタケースの表（品ごとの用意の仕方、取る手、1本・1トレーから取れる数、見た目、並び順） |
| `src/prep.ts` | 朝の仕込みの表（仕込みごとの材料と、どの品を満たすか） |
| `src/tuning.ts` | 調整用の数字（値段・時給・魚屋さんの代金・時間・許容幅など） |
| `src/ledger.ts` | 一日の帳簿（売上・魚屋さんへの支払い・給料） |
| `src/layout.ts` | 板場の寸法（カウンター・つけ台・まな板の奥行き、通路幅、高さ、腕の届く範囲）。変更後は `npm run layout` でシーンの配置に反映 |
| `src/assets.ts` | アセット（3D モデル・音など）の一覧 |
| `src/components.ts` | コンポーネントの一覧 |
| `src/scene-assets/` | コードで作る 3D モデル |
| `public/scenes/` | シーンの配置データ（JSON） |
| `public/ui/` | UI パネル（`.uikitml`） |

## 制作ルール

- アプリ内の文字はすべて英語
- 実在の企業名・ブランド名・商品名は使わない
- 外部の 3D モデル・画像・音・フォントは使わず、図形をコードで作る
- Meta Quest 実機で 60fps 以上を目標にする
- 使用素材はすべて [CREDITS.md](CREDITS.md) に記録する
