# Sushi VR

寿司をテーマにした WebXR アプリです。
Meta Quest などの VR ヘッドセットのブラウザで URL を開くだけで、インストールなしで遊べることを目指しています。

> 昭和の寿司屋の板場に座り、ハンドトラッキング（手の動きの読み取り）だけで握りを1貫ずつ作って出せます。パソコンのエミュレーターで作って確かめたもので、ヘッドセットの実機ではまだ試していません。

## 2つの遊び方

- **握りステージ**（はじめての人はここから。`src/stage.ts`）：座って手を洗うと、もうお客が座っています。ネタケースは満タン、おひつにはシャリが入っています。ワールドの番号がお客の人数です（ワールド1〜3）。各ワールドに4つのステージがあり、注文に出るネタが増えていきます（基本のネタ → ネタを追加 → 締めもの・貝・軍艦 → 全部）。最後のお客が帰ると、出した握りの出来を平均します（Excellent 100、Good 75、Poor 40、Bad 0）。65点以上でクリアになり、次のステージが開きます。点数は帳場の結果の板に出ます。
- **実務（1日営業）**：朝の仕込み、営業、閉店まで。かんたんと本格があります（下の説明）。

ステージや1日が終わったら、電話を指さしてつまみます。カードのいちばん上が「Next stage」「Try again」「Next day」です。遊び方とステージは、電話の Settings で選びます（「Start」でページを読み込み直します。ヘッドセットでは、もう一度 VR に入ります）。

**一時停止**：ヘッドセットのメニューを開いている間や、ヘッドセットを外している間は、ゲームの時間が進みません（`src/pause.ts`）。お客は待ちくたびれず、タイマーも火も止まり、「Paused」と出ます。戻ったとき、手に持っていた物はそのままです。

## 朝の仕込み

毎日、開店前の仕込みから始まります。仕込みの間は、お客はまだ来ません。おひつは空で始まります。ケースの中身は難易度で変わります。難易度は、帳場の壁(電話と呼び出しボタンの間)の木の札に出ています。魚屋さんに電話するまでは、札を指さしてつまむと切り替わります(次からも覚えています)。

- かんたん:仕込む品はケースが空、仕込まない品は満タンで始まります(職人が用意してくれています)。毎日まっさらから始まります。
- 本格:ケースの残りが次の日に持ち越されます(その日を締めたときにブラウザに保存。1日目は空のケース)。自分でケースを見て、要るものを注文します。日持ちさせてよいのは、マグロと火を通したもの(穴子・煮はま・玉子・タコ・鮑・かんぴょう・稲荷の揚げ)だけです。ウニといくらは2営業日、ツマものは3日です。ほかの品は、前の日の残りが朝にケースから下げられます(ケースの上にお知らせが出ます)。ツマもの(きゅうり・大葉・たくあん・梅肉)は八百屋さんから直接、魚と一緒に届いて足りない分が補われます。電話では頼みません。このゲームにお金はありません。値段も支払いもないので、注文は品ごとに決まった量の段階だけで決まり、職人とアルバイトも、呼ぶか呼ばないかだけです。出来合いの品は、4人前でケースいっぱいです(車海老4本、赤貝・トリ貝は4つずつ)。ホタテは1パック9個(1個で1貫。パック単位でしか頼めません)、稲荷の揚げは12枚で1セット、甘海老は1シート18尾(6尾×3列、2尾付けで9貫)です。

**米と海苔**(本格だけ。`src/pantry.ts`):使うと減り、次の日に持ち越されます(ブラウザに保存)。1日目は、炊く前の米が10 kgの袋で1つ、海苔が30枚から始まります。数字は仮のものです。

- ご飯は1回に1升か1.5升炊きます(1升 = 炊く前の米1.5 kg。袋から出します)。1升でシャリが約3.3 kg、握りで約170貫ぶんです。袋の米が足りないと、火が点きません。
- 営業のシャリはおひつから取ります。握りと軍艦は19 g、巻物(鉄火巻も)は90 g、稲荷は30 gです。おひつが空だと取れません。
- 海苔は、軍艦の帯が1枚の6分の1(6切り)、巻物が半分です。
- 営業中にご飯が足りなくなったら、大将が選びます。
  - 自分で炊く:作業台へ移って、もう一度炊飯器に火を点けます(1升か1.5升)。そのあとは朝と同じ手順です(飯台、合わせ酢、しゃもじ、おひつ)。おひつを作業台へ持っていっている間は、カウンターでシャリが取れません。
  - 職人に頼む:電話の職人の欄から頼みます(1升か1.5升。約80秒でできます)。
  - かまどは1つです。どちらかが炊いている間は、電話の職人の欄に「cooking」(職人が炊いている)か「cooker in use」(大将が炊いている)と出て、頼めません。
- 米屋さんは電話にあります。米の袋と、海苔10枚入りのパックを頼めます(1回の電話で袋3つ、パック5つまで)。数秒で届きます。
- 少なくなると、おひつと海苔の缶の上にお知らせが出ます。おひつは残り約40貫で黄色、約10貫で赤、袋の米は1升を切ったとき、海苔は10枚を切ったときです。親方も、それぞれ少なくなったときに1回だけ言います(「The shari is getting low」「Shari nearly out: cook more」「Rice is low: call the rice shop」「Nori is low: call the rice shop」)。ご飯をもう炊いている間は、おひつのことは言いません。

時間は実際の店より速く進みます。仕事は並べて進めます。ご飯と鍋を先に火にかけ、煮えている間に魚を切ります。

1. 右手側、通路の右端の壁の帳場にある黒電話を指さしてつまむと、受話器が上がって魚屋さんに電話がかかります。かんたんでは、魚屋さんが「おまかせ」で持ってきてくれます。本格では、受話器が上がったまま注文します。
   - ケースに手を入れると戸が開き、品ごとに名前と在庫が出ます(売り切れの品も)。品をつまむと注文に入ります。つまむたびに次の量になり、最後はなしに戻ります。
   - 仕込む品は、その材料を注文します。マグロはどれをつまんでもマグロの腹(16分の1か8分の1)、ハマチは四分の一か半身、ほかは1つずつです。仕込まない品は、そのまま出せる形で、ケース半分か満タン分です。
   - ケースの左端の上の伝票に、注文した品が出ます。電話をもう一度指さしてつまむと、電話を切ります。
   - 届くのは注文した分だけです(そのまま出せる品は、すぐケースに入ります。`src/fish-order.ts`)。
   - 少しすると、発泡スチロールの箱が、まな板の左に届きます(中のものを全部仕込み終わると、空の箱は片付きます)。丸の魚の長い箱は、後ろの流しの左横の台に届きます。その間に、体ごと後ろの流しへ振り向いて手を洗います(洗っていない手では魚に触れません)。
   - 遠くのもの(電話・呼び出しボタン・給湯器・のれん・作業台・ガス台)は、手を前へ伸ばし、ほかの指を握って人差し指で指し、つまみます。
2. ご飯を炊きます。作業台の前へ移り、台の下のガス炊飯器を指さしてつまむと、火が点きます(本格では、横に出る2つの印のどちらか、1升か1.5升をつまみます)。炊けると火は自然に消え、蒸らしに入ります(台の上に残り時間が出ます)。
3. ガス台。箱の一番上に、魚屋さんが下処理を済ませたタコ・穴子・鮑と、網袋に入った生きたはまぐりが入っています(かんぴょうは煮たものを買うので、仕込みはありません)。それぞれを取って(どちらの手でも)、ガス台のその品の鍋の上で離します。ガス台の前からも、カウンターの方へ向けば箱に手が届きます。火口ごとに、ガス台の正面につまみがあります。短くつまむと強火で点き、もう一度で消えます。つまんだままでいると、強火・中火・弱火と一段ずつ下がります。タコと鮑は魚屋さんのステンレスの中子(なかご)に入って届きます。穴子は開いてあるものをパック(白い発泡トレー)で買います。4つとも鍋に入れたら、空いた中子は箱の中で1つの山に重なるので、1つずつ片付けます。まず穴子の空きパックをつまんで足元のゴミ箱へ。次に中子を山の上から1つ(椅子から)つまみ、流しを向いて水槽の上で持ったまま、もう片方の手でこすると洗えます。洗えたら、その手で流しの手前の縁に掛けてある乾いた布巾をつまみ、中子をなでると水分が取れます(離すと布巾は元の場所に戻ります)。乾いたら、砥石の手前(流しの端の台)で離すと伏せて重なります。下の魚に手を付ける前に、親方がこれを指示します。片付けないままでは開店できません(アルバイトの片付けには含まれます)。
   - タコ:強火で、ぐらぐら沸かして炊きます。炊けたあとも煮続けると、硬くなります。
   - 穴子:煮汁を90℃に保って煮ます(鍋の上の数字が温度計です)。強火で上げてから、沸く前に弱火へ落とします。沸かすと身が崩れます。
   - 鮑:煮汁がなくなるまで煮切ります(鍋の上に残りが出ます)。なくなったら、焦げる前に火を止めます。
   - はまぐり:強火で沸かし、殻が開いたら(煮えるにつれてふたが持ち上がります)火を止めます。煮続けると硬くなります。煮汁(お吸い物用に鍋に残ります)から身を出し、ケースではなくまな板の上で離します。熱いので、少し(8秒)置いて冷まします。そこからは魚と同じようにまな板で仕事をします。両手で殻から外し(イカの足と同じ引き離し)、包丁を真ん中に1回引いて開き、わたを引き離し、ツメを刷毛で塗ります。ツメ壺はまな板の右のカウンターにあり、刷毛が差してあります。刷毛の柄をつまんで身の上をなで、離すと壺に戻ります。開いた身はケースへ、殻とわたはゴミ箱へ。まな板がふさがっているあいだは、火を止めた鍋の中で待たせておけます。
   - 煮えたら火を止め、鍋から出して、ケースの上で離します(まな板の前に戻って)。使った鍋は流し台の下の物置に戻ります。本格では鍋は全部その物置(右の戸の奥)に入っていて、箱から材料を取る前に右の戸の取っ手をつまんで開け、鍋を上からつまんで火口の上で離します。
   - 玉子(本格だけ。このお店のやり方:貝柱入りの厚焼きを店で焼く):生地は店で作ります。すり鉢は流し台の下の物置にあります。左の戸の取っ手をつまむと戸が開くので、すり鉢を縁でつまんで(すりこぎと菜箸は中に入っています)作業台の上で離すと、作業台の奥、流し側の角に置かれます。箱から貝柱と卵を取り、すり鉢の上で離すと、貝柱が入り、卵のパックが横に置かれます。すりこぎをつまんでぐるぐる回し、貝柱をすり身になるまで擂ります。卵のパックをつまむ(たたく)と卵が全部入ります(割る工程は省きます)。混ぜる前に塩ひとつまみと砂糖小さじ1を入れます。奥の壁の食品棚へ移動して塩の壺をつまみ、すり鉢の上で離します。砂糖の壺も同じです。そのあと菜箸をつまんで、泡立つまで回して混ぜます。ガス台の横の壁の網の隣に、四角い銅の玉子焼き鍋が掛かっています。木蓋は鍋とセットで、鍋の中に入れて一緒に掛けてあります。持ち手をつまんで外し、鍋が片付いた火口の上で離し、中火で温めます。鍋が熱くなると、鍋の上に緑の「Ready」が出ます(生地を流し込むまで出ています)。そうしたら油返しをします。油は調味料なので、食品棚の塩・砂糖の段にオイルポットがあります。熱い鍋の上で離すと、油が鍋肌に回って、余分はポットに戻ります。すり鉢の手前の縁をつまみ、鍋の上で離すと流し込まれ、熱くて油がなじんだ鍋なら「ジュッ」と鳴ります(冷たい鍋や油なしだと貼り付きます)。火を弱火に落とします(強火や中火は早く焼けますが、下の面が焦げます)。片面がしっかり焼けたら、チャーハンのように返します。鍋のふちに置いた菜箸を片手で持ち、もう片手で持ち手をつまんで、勢いよく振り上げるとクルンと返ります(焼ける前に返すと崩れます)。もう片面も焼けたら火を止め、木蓋を桟(上の棒)でつまんで外し、鍋の玉子の上で離して乗せ、手のひらで一度押して四角く整えます。持ち手を持ち上げると、鍋と木蓋が一緒にひっくり返り、玉子が木蓋に乗って作業台に出ます。そこで少し冷まして(15秒)から、つまんでケースの上で離します。鍋は洗剤を使わず、熱いうちにキッチンペーパーで拭くと、木蓋と一緒にフックに戻ります。時間は目安で、点にはなりません。焦げた面・貼り付き・崩れがあると、取れる貫数が少し減ります(`src/tamago-system.ts`)。
4. 魚の柵取り。左手で箱の魚をつまみ(上にあるものから)、まな板の上で離します。魚は紙で包んだ上からビニールに入っています。左手で押さえ、右手で包みをつまんで引き離します。これを2回です。左手で押さえ、包丁を白い線に沿って引きます。線は、魚に沿って手前に引くもの、横に切るもの、まな板に沿って低く削ぐもの(皮)があります。包丁は刃を立てて、右から左下へ引くのが基本です(刀やバットと同じストローク)。刃を寝かせるのは、皮や中骨を削ぐ時だけです。わさびの皿は、営業中以外は伏せてあります。
   - マグロ(まぐろ屋から買う腹の8分の1・16分の1):皮目を切り落としてから、大トロ・中トロ・赤身に分けます。
   - カツオの半身:血合いに沿って背と腹に分けます。背は血合いを落とし、皮は包丁で削ぎます(引くと身割れしやすいため)。腹は首まわりの硬い皮と血合いを落とし、氷の上へ戻します(7で焼きます)。
   - イカ:胴から足を引き抜き、ワタを切り離し、足と胴をそれぞれ開いて平らにします。身の皮は手で剥ぎ(包みと同じく引き離す)、ペーパー箱の紙で水分を拭きます。
   - できた柵をつまんでケースの上で離すと、その品の場所に入ります(イカの足はゲソ)。包み・皮・血合い・ワタ・使ったペーパーは、まな板の右手前にたまります。左の足元のゴミ箱(手が近づくとふたが開く)に捨てます。
5. 丸の魚(このお店のやり方:中型の魚は丸で、大きい魚はケースに入る分だけ買う)。しまあじとヒラメは丸で、ハマチは半身で、長い発泡の箱に入って、流しの足元(食器棚の前)の低い台に届きます。振り向いて流しの横の台(左手側)を指さしてつまむと、その前に立ち、箱から魚を取れます。流しを指さしてつまむと、流しの前に立ちます。
   - 水洗い:魚を箱から取って、流しの上に渡した水洗い用のまな板に置きます。流しの右の台にある鱗取りをつまんで、魚の上で何度もこそげると、鱗が取れます。魚をつまんで少し持ち上げると裏返るので、裏も同じようにします。鱗取りの隣の出刃包丁を拳で握って、頭を落とします(しまあじは腹も開きます)。左手で魚を押さえ、右手でワタをつまんで引き出したら、水を流して腹の中を手でこすって洗います。頭とワタは、流しの横のゴミ箱に捨てます。
   - おろす:洗った魚を持ってまな板の前へ戻り、まな板に置きます。しまあじは三枚おろしです。腹を手前にして、腹側と背側を骨まで切り、身を持ち上げて外します。裏返して同じようにし、中骨は捨てます。ヒラメは五枚おろしです。黒い方を上にして、真ん中を骨まで、両側はヒレの際を切り、背側と腹側の身を外します。裏返して白い方も同じにします。
   - 身ごとの仕事:腹骨をすき取り、骨抜き(まな板の奥、ペーパー箱の右)で小骨を抜きます。骨抜きはつまんで持ち、先を小骨に当てて上へ抜きます。次に、包丁で皮を引きます(中型の魚は柵にする前に皮を引く)。最後に、背と腹の柵に分けます。ヒラメの身は、代わりにエンガワを切り離します。ハマチの半身は、包みを外し、腹骨・小骨・皮のあと、背と腹に分けます。
   - 最後に水気を取ります(このお店のやり方:白身は水気を取ればReady)。ペーパー箱から1枚取り、柵の上をなでます。
   - 柵とエンガワは、全部ケースに入れます。
   - 本格では、小肌とサバもその日に仕込みます(このお店のやり方)。
     - 小肌は丸で届き、1日8尾を丸づけで8貫にします。流しの洗い板の右にばらで置かれ、左に氷を入れたボウルがあります(並べない)。同じ魚がいくつもあるときは、工程ごとにまとめてやります(狭い店の動き方)。鱗を取ったら、1尾ずつ真ん中へ取って頭を落とし(1尾ずつ。まとめて落とさない)、氷の上へ。頭を全部落としたら、1尾ずつ氷から取って背びれを切り落とし、腹を切り落とし、包丁の先でワタを出します(小肌は腹を裂きません)。全部洗ってまた氷の上へ。魚は頭を左に置きます(左利きなら逆)。
     - まな板でも同じで、先に全部を腹から開き(腹開き)、そのあと全部の中骨をすき取ります。捌く時は頭を右に置き換えます(腹は手前のまま。頭を落とす時は左)。開いたものは、重ねて一列に並べます。
     - サバは、しまあじと同じように水洗いして三枚におろし、腹骨と小骨を取ります。皮は残します(握る前に手で剥ぐ)。
     - 塩(両面):小肌は流しの横の台の平ざる。まずザルに塩をふり(塩の器から塩をつまんで、ザルの上で指を開く。落ちた所が白くなる)、開いた小肌を皮を上にして一列に重ねて並べ、上からも白くなるまで塩をふります。サバはステンレスのバットに入れて、白くなるまで塩をふります。
     - 置く:小肌はだいたい40分、その日の大きさで5分前後します(魚屋さんが電話で言います)。サバは2〜3時間。ここでは1分が1秒です。時間は食器棚の流し側の側面(お客さんから見えない所)に掛けたキッチンタイマーに出ます。0になると鳴って点滅します。
     - 小肌の塩を落とす:流しに置いた水を張ったボウルに小肌を入れると、塩が落ちます。そのあいだにザルの縁をつまんで蛇口の下で洗います。ザルが洗えたら、小肌をボウルからきれいなザルへ上げ、一列に重ねて並べて水を切り、そのまま酢へ移せます。水と水切りは時間ではなく、手順です。
     - サバの塩を落とす:バットの手前の縁をつまんで蛇口の下に持っていき、塩が落ちたら離します。
     - 酢:酢専用のホーローの容器は1つで、台のいちばん奥にあります。小肌が先、サバはそのあとです。魚をつまみ上げて容器の上で離します。小肌は20分、サバは30分。使い終わったザルやバットは片付きます。
     - 取り出す:容器の上でつまんで持ち上げ、ケースの上で離します。時間はこのお店の目安で、親方が教えてくれます。店によってやり方が違うので、時間で点や数は変わりません(`src/cure-system.ts`)。時間の少し前に、親方が「用意して」と流しの横の台へ呼びます。
6. シャリ(このお店のやり方:合わせ酢は米酢の作り置き、あおがない)。炊き上がったら、もう一度炊飯器を指さしてつまむと、作業台の飯台にあけられます。合わせ酢の器を持って、ご飯の上にかざすと打たれます。しゃもじを持って、ご飯を切るように何度も往復させます。次に、座る位置の横の台からおひつを持ってきて(ふたは台に残します)、作業台の飯台の横に置きます。しゃもじでシャリをすくって、おひつへ何回も移し(6回)、おひつを元の台へ戻します。営業のシャリは、このおひつから取ります。飯台としゃもじは壁に戻ります。
7. カツオの腹。氷の上から、まな板へ移します。手前の端にある金串の輪をつまんで奥へ押し込み、皮目に金串を打ちます。ガス台の横の壁に掛かった網を、鍋が片付いた火口に置きます。網の上に腹を皮目を下にして置き、その火口を強火にします。金串の輪をつまむと、4分の1ずつ回ります。下になった面が焼けます。皮目は焼き目が付くまで、ほかの面は色が変わるまでです。焼けたら金串を持って持ち上げ、氷の上で締めます。それからまな板の上でペーパーで水気を取り、金串を手前に引き抜いて、ケースの上で離します。
8. 掃除をします。
   - 包丁を拭いて置きます。
   - まな板の手前の縁をつまんで振り向き、流しで洗います(もう片方の手でこする)。流しの上で離すと立てかけられ、しばらく乾かしてから板場に戻します。
   - ガス台の火は全部消します。
   - 石けんで手を洗います。
   - 包丁を研ぎます(朝の1回)。包丁を持って振り向き、流しの横の台の奥にある砥石をつまんで、流しの水槽の中で離すと、濡れて(色が濃くなって)台に戻ります。もう片方の手で刃を押さえ、刃先を砥石の上に置いて往復させます。研げたら刃を水槽に入れてすすぎ、前を向いて拭いて、箱に置きます。切れ味は切るたびに落ち(45回ほどで切れなくなる)、切れない包丁で切った品は減点です。切れない包丁は、ときどき(ランダムに)身に食い込んで一回の引きで切り身が離れず、もう一度引くことになります。仕込みと営業の間の研ぎは必ず、閉店前の研ぎは任意です。
   - 最後に、客席の奥の店の入口に掛かっているのれんを指さしてつまむと、のれんが外に掛かって開店し、最初のお客が入ってきます。

切り口が線に近いほど高く評価されます。切り口が曲がると身が無駄になり、柵から取れる枚数(出せる貫数)が減ります。ガス台の品も評価されます(硬くなったタコ、崩れた穴子、硬くなったはまぐり、焦げた鮑、焦げたり片面しか焼けていない腹は、取れる貫数が減ります)。仕込みが終わると、取れた貫数がまな板の上に出ます(仕込みは店によってやり方が違うので、評価の言葉は出しません)。ハマチは季節で大きさが変わる魚です(冬は大型、夏は準大型)。季節を入れるときに、届く形も季節に合わせます。それまでは半身で届きます。

**後ろの列へ一歩**:作業台とガス台は、座る位置からは一歩先です。洗う丸の魚があるあいだは、流しもそうです(座る位置からは、流しの手前の縁にしか手が届きません)。振り向いてどれかを指さしてつまむと、画面がまばたきして、その前に立ちます。そこからもう一方を指せば移り、カウンターの方を向いてまな板を指せば座る位置へ戻ります。開店すると、座る位置に戻ります(`src/place-system.ts`)。

**人を頼む**:ふだんは誰もいません。仕込みの間に、帳場の食品棚の上にある呼び出しボタン(左が職人、右がアルバイトの絵)を指さしてつまむと、その人を呼べます。もう一度でやめになります。呼んでいる間は、ボタンの上のランプが点きます。呼ばれた人は、通路の左端の調理場の出入口から出てきて仕事をし、終わると調理場へ戻ります(シンプルな人形です)。

- 職人:箱のところへ歩いてきて、残っている魚を調理場へ持っていき、柵にしてケースに入れてくれます。ガス台の材料は煮て、職人が切ったカツオの半身の腹は焼いて入れてくれます。シャリは親方(自分)の仕事です。
- アルバイト:仕込みが終わると、まな板のところへ来て、ゴミを捨て、まな板を洗ってくれます。

給料はありません。呼ぶか呼ばないかだけです。かんたんモードで仕込まない品が満タンなのは、職人が用意してくれた分です。

## 店のまわり

- 振り向き:ヘッドセットでは、座ったまま体ごと後ろを向くだけです(画面の切り替えはありません)。顔がカウンターから120度より後ろを向くと「後ろ向き」、60度より前に戻ると「カウンター向き」になります。横(帳場やガス台)を見ただけでは変わりません。
- ネタ表:流しからガス台の上の壁に、木札が32枚並んでいます。品の名前が日本語の縦書きで、右から読みます(ゲーム内で日本語が出るのはここだけです)。
- 帳場:お客から見えにくい、通路の右端の壁です。手前に食品棚(調味料が分かるように並べてあり、ラベル付き:醤油・みりん・酒・米酢・塩・砂糖)とその上の呼び出しボタン、奥の食器棚との間に、電話台の黒電話と、その上にその日の結果の板があります。
- 長のれん:カウンターの右端の、客席と板場の間の通り口と、通路の左端の調理場の出入口に、藍色の長いのれんを掛けました。客席からは、帳場が少しだけ見えます。調理場の明るさは、のれんの合わせ目と裾から見えます。

## 営業と閉店

- 握りを出すと(巻物は1本で1注文)、出来が Excellent・Good・Poor・Bad で付き、お客の頭の上に出ます。
- 出来(拍・わさび・ツメ・向き・利き手・鮮度・衛生)で、お代わりが変わります。お客は3注文のつもりで来ます。Excellent なら1つ増え(最大6つ)、Poor なら1つ減り、Bad ならそれで終わりにします。直すところは小さな印で出ます。
- 注文と違う品は「Not my order」で返されます。作り直します。
- カツオの注文で背か腹の指定がなければ、背と腹の2貫を1つずつ出します。
- ツメ(このお店のやり方):穴子と煮はまの握りは、わさびなしでツメを少し塗ります。握り終えたら(指の上でも下駄の上でも)、まな板の右のツメ壺から刷毛の柄をつまみ、握りの上を1回さっとなでて離します(刷毛は壺に戻ります)。ネタに照りが付きます。塗らずに出す(ほかの品に塗る)と10点減り、ツメの印が出ます。練習モードでは Tab で塗ります。
- 車海老(このお店のやり方):ケースには活けの車海老が入っていて、注文ごとに茹でか生かが決まります。左手でケースから1尾取り、まな板の上で離します。茹で:尾の後ろに竹串が一直線に置いてあるので、串の平たい端をつまんで奥へ押し、腹側に沿って刺します(茹でてもまっすぐのまま)。串を持って、まな板の左のカウンターにある沸かしっぱなしの鍋の上で離します。10秒ほどで鍋の上に Ready の札が出るので、串を持って取り出し、鍋の横(まな板寄り)の氷水のボウルの上で離して締めます。数秒で小さな音が鳴ったら、串を持ってまな板の上で離し、串を手前へ引き抜きます。生:串も鍋も使いません。どちらも最後に殻をむきます。左手で身をつまみ、右手で頭をつまんで、殻ごと引き離します(尾は残ります)。左手でつまむと指の上に乗り、あとはいつもの握りです。茹で時間が10秒から大きく外れる(足りないと中が生、長いと硬い)と5点か15点減り、鍋の印が出ます。練習モードでは Tab で1手ずつ進みます。車海老を選んで 7 を押すと、茹でと生を交互に注文します。
- お金はありません:このゲームは経営ゲームではなく、板前のシミュレーターです。値段も勘定も給料もなく、お勘定は画面の外でレジの人がします。最後の1貫を食べたお客は「Thank you!」と言って入口から帰り、次のお客が入口から入ってきます。
- お茶:お客は、最初の1貫のあとに、ときどきお茶を頼みます。お茶は粉茶で、電話の下の低い棚にある給湯器で、お客から見えないところで入れます。
  - 誰も呼んでいないときは自分で出します。給湯器を指さしてつまむと、少しして、まな板の右の台に湯呑みが出ます。それをつまんでケースの上を越え、つけ台の上で離すと、お客の前に置かれます。
  - 待たせすぎると、そのお客の注文が1つ減ります。
- 営業中のアルバイト:ボタンで呼ぶと、帳場の長のれんの奥にいて、通り口から出てきます。新しいお客を入口から席まで案内し、頼まれたお茶を持っていきます。営業中のまな板拭き・布巾洗いは、板前の仕事(衛生)なので、自分でやります。
- 閉店:店の入口の外に掛かったのれんを指さしてつまむと、のれんを中にしまいます(指さしで腕を伸ばした手は、ネタケースの上を通っても扉を開けず、何も取りません)。座っているお客の注文がラストオーダーです。お客が帰ると、帳場の電話の上にある結果の板が、その日の締めになります(カウンターの上にお知らせが出ます)。結果の板には、営業中も今日の数字が出ています。
  - 出した貫数
  - 出来ごとの数(Excellent・Good・Poor・Bad)
  - 本格では、朝に捨てた分(日持ちを過ぎた品の数と貫数)
- 次の日は、電話を指さしてつまみ、カードの「Next day」をつまむと始まります(ページを読み込み直しても同じです。本格では、ケースに残った分を持って次の日になります)。

練習モードのキー(仕込み):9 運ぶ(魚・柵・ゴミ)、0 引き離す(包み・足・皮)、X 切る、- ペーパー(開いたはまぐりにはツメの刷毛)、[ まな板(持ち上げ・洗う・立てかける・戻す。間に T で振り向く)、] のれん(開店と閉店)、= 電話、Shift+= 難易度の札、; 職人のボタン、' アルバイトのボタン(どれも指さしてつまむ)。本格の電話中は、Tab で半分を切った品を全部、満タン分注文してから電話を切ります。Shift+8 で、本格の店を1日目からやり直します(次の読み込みから)。Shift+K で利き手を左右切り替えます(朝、電話の前だけ)。D で包丁を研ぎます(流しを向いて。砥石を濡らす→研ぐ→すすぐの順に1回ずつ)。営業中は、, 給湯器(Shift+, でお客がお茶を頼む。練習用)、. 湯呑みをつけ台へ。O は仕込みを飛ばして開店します。後ろの列では、A でシャリの次の手順(本格の営業中は、かまどが空いていれば1升の炊き足しに火をつけ、その先の手順へ進みます)、Enter でガス台の次のこと(つまみ・鍋に入れる・ケースへ出す・網・カツオの腹)をします。どちらも、必要なら移動と振り向きもします。/ で見ている方へ移り(作業台・ガス台・まな板へ戻る)、Tab で親方が言っていることをします(丸の魚の仕事、鱗取り・裏返し・出刃・水洗い・骨抜きも Tab で)。` で手ブレ試験(手が揺れ、ときどき一瞬見失う。実機なしで判定の強さを確かめる用)。Shift+D で刃をほぼ切れない状態にします(食い込みの試験用。引いても切れなければ、もう一度引く)。

このゲームは手だけで操作します(ハンドトラッキング)。コントローラーを持っていて手が見えないときは、目の前にお知らせが出ます。パソコンのエミュレーターは最初、立った人(目の高さ1.6m、手は胸の高さ)とコントローラーの状態で始まるので、開発中は起動時に、手のモードで、座った目の高さからまな板を見下ろし、両手をまな板の上に置いた状態にします(上の手の絵のボタンで、手とコントローラーはいつでも切り替えられます)。

**視線(Meta VR Glasses)**:目の向きを読める機械では、指さしで選ぶもの(電話、呼び出しボタン、給湯器、のれん)を、見てつまむ(空いている手のどちらでも)でも選べます。見ている間は、指さしと同じように光ります。手元で何かを持ち上げたつまみ(ネタ、湯呑み、箱の魚)は作業なので、選んだことになりません(`src/gaze.ts`)。Quest 3 / 3S は目の向きを読めないので、指さしだけです。メガネの視野は狭く(左右37°、上25°、下43°)、まな板を見下ろしたとき、ネタケースの両端、包丁、布巾、発泡スチロールの箱、おひつは視野の外になり、頭を向けて見ます。エミュレーターでメガネを試すには、`iwsdk.config.json` の `dev.emulator.device` を `metaVRGlasses` にします(ふだんは `metaQuest3`)。

判定は Meta の手の設計ガイドに合わせています。手を0.4秒未満見失っても、持った物は落としません(握るときに片手がもう片手を隠すため)。手には振動がないので、取る・置く・押す・結果のたびに短い音が鳴ります。

## ネタケース

幅150cmのケースに32品が並びます。左から順に、次のとおりです。

- 左手（ネタの手）で取る品：玉子、鮑、タコ、イカ、ゲソ、ヒラメ、シマアジ、ハマチ、カツオ(背・腹)、マグロ（赤身・中トロ・大トロ）、コハダ、アジ、しめ鯖、車海老、甘エビ、ホタテ、赤貝、トリ貝、穴子、煮はま、稲荷の揚げ
- 右端の、右手で扱う品：ウニ（白木の折に身を重ねて並べ、小さな木べら付き）、イクラ（素朴な白い陶器の浅鉢に盛り、スプーン付き）、胡瓜、干瓢(煮たものを買う)、沢庵、梅肉、大葉（巻物の具。鉄火巻の芯はケースの品ではなく、注文が入ってから赤身の柵をまな板で切ります）

引き戸5枚は、どちらの手が近づいても自動で開きます。手を入れると、指先の品が光って名前が出ます。同時に、開いた扉の奥の品が、ケースの上に2倍の大きさで名前付きで浮かびます。

**軍艦（ウニ・イクラ）**は手のひらではなく、まな板の上で作ります。作り方は次のとおりです。

1. 右手で手水とシャリを取り、一度グーにして握ります(成形)。
2. 右手をまな板の手前半分(自分の側)に下ろすと、シャリがまな板に置かれます(握る前のシャリや、奥半分には置けません)。
3. 海苔は二点留めで巻きます。左手でまな板の左奥の海苔缶から帯(6切り:1枚を6つに切った3.5×19cm)をつまみます(手を近づけるとふたが開きます)。シャリは縦向き(長い方が奥へ向く)に置かれています。帯をシャリに近づけると、帯の端がシャリの手前の端(下部)に合わさります。その端を右手の人差し指で押さえ、左手をシャリのまわりに一周させると、海苔が奥の頂点をクルッと回り(小さく音が鳴ります)、最後は巻き始めの上に重なります。指はほとんど巻き終わるまで離さないでください(早く離すと海苔が外れます)。最後に帯の端を少し外へ引いて(ピンと張って)から離します。張らずに離すと海苔がゆるく、点が少し下がります。
4. わさびの注文があれば、人差し指で付けます。
5. 右手でウニは木べら、イクラはスプーンを取り、軍艦の上で離すと乗ります。

海苔はすぐしんなりするので、鮮度は巻いた時から数えます。

**稲荷**は関東風の俵形です。作り方は次のとおりです。

1. 右手で手水とシャリを取ります。
2. 左手でケースから味付けの揚げを取ります。揚げは、パックから汁ごとステンレスの中子に移してあります。
3. 両手を合わせると、シャリが揚げに入ります。
4. 左手のこぶしで、拍に合わせて口を折り込みます。

わさびは付けません。

**巻物**は6種です(かんぴょう巻・鉄火巻・かっぱ巻・おしんこ巻・梅しそ巻・梅きゅう巻)。巻物の注文が入ると、まな板の上に巻き簾が広がります。作り方は次のとおりです。

1. 左手で海苔缶から半分の海苔を取り、巻き簾の上で離します。
2. 右手で手水とシャリを取り、開いた手で海苔の上を左右になでて広げます。
3. わさびの注文があれば付けます。
4. 右手でケースの右端から具を取り、真ん中に置きます(梅しそは大葉 → 梅肉、梅きゅうは梅肉 → 胡瓜)。鉄火巻は中太です。海苔の半切れは縦(長い辺を奥へ)に置き、芯はケースの品ではなく、左手で赤身の柵をまな板に出して包丁で1枚切り(端材と合わせた芯のつもりです)、包丁を拭いて置いてから、左手でその切り身を飯の真ん中に置きます。
5. 両手で巻き簾を前へ押して巻き、両手のこぶしを拍に合わせて締めます。
6. 包丁で目印の線を3回切ります。1回目で半分にすると、2本が横に並びます。かんぴょう巻は六切り(2本まとめて3等分)、ほかは八切り(半分、4本並べてもう一度半分)、中太の鉄火巻は2回で四切り(半分、2本並べてもう一度半分)です。包丁を拭いて置きます。
7. 断面を上にして立った巻物をつまんで下駄に置き、出します。下駄は座ったまま腕を伸ばした先より少し遠いので、ケースの向こう半分の上(ガラスの上から手を入れる)で離せば、下駄に置いたことになります(握りも同じ。`src/layout.ts` の `GETA_ZONE_*`)。

握りの形は、お店のやり方の舟形(底が平らで、上がゆるく盛り上がり、両端が丸く細くなる)です。シャリは約19g(長さ5.6cm・幅2.5cm・高さ2.1cm)。手水を付けて取ったシャリは、はじめはばらけた塊で、拳で丸めると玉になります。そこから三手の一手ごとに締まります。一手目で上(ひっくり返した後の底)が平らになり、二手目で形が決まってネタがかぶさり、三手目で左右がそろって仕上がります。ネタは長さ7.5cm・幅3cm・厚さ6mm(柵から切った場合)で、シャリに沿ってかぶさります。玉子・鮑・帆立のように硬いネタは、あまり曲がりません。形は `src/scene-assets/lib/nigiri-form.ts` で作っています。

握りは25種です。柵から切る14種(マグロ、カツオの背と腹、白身とヒラメのエンガワ、しめさば、イカ、タコ、鮑、玉子)は、1枚切るごとに短くなります。仕込み済みの9種は、1枚ずつ指に取ります。車海老は活けで置き、注文ごとに茹でか生で仕事をします(下記)。なくなった品は売り切れになり、翌朝の仕込みまで注文にも出ません。数と並び順は `src/menu.ts` で変えられます。

English version: [README.md](README.md)

## 動かし方

Node.js 22.12 以上が必要です（[`.nvmrc`](.nvmrc) 参照）。

```sh
npm install
npm run dev
```

開発用のブラウザが起動します。VR ヘッドセットがなくても、内蔵のエミュレーター（IWER）でパソコン上から VR 操作を試せます。
ブラウザ内の Runtime / Editor の切り替えで、アプリの実行画面とシーン編集画面を行き来できます。

本番用ファイルの作成:

```sh
npm run build   # dist/ に出力
```

## 制作ルール

- アプリ内の文字はすべて英語
- 実在の企業名・ブランド名・商品名は使わない
- 外部の 3D モデル・画像・音・フォントは使わず、図形をコードで作る
- Meta Quest 実機で 60fps 以上を目標にする
- 使用素材はすべて [CREDITS.md](CREDITS.md) に記録する
